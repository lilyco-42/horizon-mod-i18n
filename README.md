# horizon-mod-i18n (`lilyco_i18n` v1.0.0)

Standalone **Horizon** native mod providing externalized `.toml` live Chinese/English localization (`L` key toggle + HUD indicator).

## Build & Install
```bash
horizon-launcher native-build \
  --version nightly-2026-11-20-0a875da \
  --trust-native-code .
```

Part of the [lilyco-horizon](https://github.com/lilyco-42/lilyco-horizon) ecosystem.
